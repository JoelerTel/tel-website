Step 1 — Create a Google Cloud Project & OAuth Client
Go to Google Cloud Console

Visit console.cloud.google.com → Create a new project called TEL Dashboard.

Enable APIs

In "APIs & Services" → Library, enable: Google Search Console API, Google Analytics Data API, and Google Ads API.

Create OAuth 2.0 Credentials

APIs & Services → Credentials → Create Credentials → OAuth Client ID. Application type: Web application. Under Authorized JavaScript origins add: https://texaselectricandlight.com. Under Authorized redirect URIs add: https://texaselectricandlight.com/pages/dashboard.html

Copy your Client ID below

After creating, copy the Client ID (it looks like 123456789.apps.googleusercontent.com).
